## About me

I've been building for the web for over 20 years, and I still enjoy it. Most of my days are spent in PHP, with Symfony, Laravel and PrestaShop: APIs, online stores and all the small tools that keep a business running behind the scenes.

I like being involved from the start, when the first technical decisions get made, and sticking around through deployment and the maintenance that follows. A lot of my work is connecting systems that weren't designed to talk to each other, figuring out why something is slow, or taking older code and making it pleasant to work with again.

## What I usually work on

- **Backend and APIs:** REST and GraphQL APIs, microservices, API Platform
- **E-commerce:** PrestaShop modules and themes, back-office tools, connectors and custom marketplaces
- **Integrations:** payment providers, ERPs, CRMs and all kinds of third-party services
- **Automation:** PHP and Python scripts, scheduled jobs, web scraping, data imports and exports
- **Legacy code:** keeping older applications alive, updating dependencies and fixing performance problems
- **Working with others:** code reviews and helping teammates get unstuck on tricky problems
